## 🔥 Argon v2.0 핵심 기능

### 1. 3대 전술 탐지 엔진 (Detection Modes)
- **비행 레이더 (`KINETIC RADAR`)**
  - 인접 프레임 차분과 지수이동평균(EMA) 배경 모델을 결합해 고속 비행 모기를 실시간 포착합니다.
  - **이동 속도 벡터(Velocity Vector) 화살표**와 **네온 플라즈마 비행 궤적**을 표시하여 모기가 날아간 방향을 즉시 추적합니다.
  - **실시간 손떨림 안정도(`STAB`) 게이지**를 통해 카메라 흔들림에 의한 오탐을 원천 차단합니다.
- **벽면 점 스캔 (`MICRO-SPOT`)**
  - 벽지, 천장, 커튼 등에 앉아 있는 미세 암점(Dark Blob)을 주변 8방향 국소 대비(`Δ Contrast`)로 분석하여 상위 3개 표적(`TGT-01~03`)을 동시 락온합니다.
- **잔상 히트맵 (`TRAIL-MAP`)**
  - 최근 8초간의 미세 비행 움직임을 열화상 플라즈마 히트맵으로 화면에 누적하여 모기의 주 출몰 경로와 은신 구역을 시각화합니다.

### 2. 4종 광학 비전 스펙트럼 필터 (Optical Filters)
- **표준 광학 (`STANDARD`)**: 왜곡 없는 원본 고화질 뷰
- **아르곤 고대비 (`ARGON`)**: 벽지나 천장의 미세한 검은 점(모기)을 배경과 극명하게 분리시키는 고대비 필터
- **야간 증폭 (`NIGHT`)**: 어두운 침실에서 플래시 없이도 피사체 윤곽을 밝게 증폭시키는 저조도 부스트 모드
- **반전 스펙트럼 (`INVERT`)**: 어두운 모기를 밝은 형광 점으로 반전시켜 시각적 인지력을 극대화

### 3. 인터랙티브 4x / 8x 광학 루페 (`Tap-to-Inspect Loupe`)
- 우측 하단 플로팅 돋보기 창에서 포착된 표적을 **4배(4X)** 또는 **8배(8X)**로 실시간 확대합니다.
- **터치 핀포인트 락온:** 화면의 의심스러운 지점을 손가락으로 터치하면 해당 위치를 즉시 고정 확대(`LOUPE LOCK`)하여 먼지인지 실제 모기인지 판별할 수 있습니다.

### 4. 전술 유틸리티 & 시뮬레이션 데모
- **소나 피치 사운드 & 햅틱 진동:** 표적 신뢰도에 따라 주파수가 변하는 Argon Sonar Ping 및 진동 알림
- **고해상도 텔레메트리 스냅샷:** 광학 필터와 HUD 마커, 타임스탬프가 합성된 증거 이미지 즉시 캡처 및 인앱 프리뷰 제공
- **시뮬레이션 데모 모드:** 카메라가 없는 PC에서도 가상 모기 비행 물리 엔진을 통해 모든 HUD와 탐지 알고리즘을 즉시 테스트 가능
