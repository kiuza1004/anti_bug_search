# 🦟 BugFinder AI - 스마트폰 카메라 모기·벌레 탐지기

스마트폰 카메라를 활용하여 눈에 잘 띄지 않는 모기, 날파리, 작은 곤충을 실시간으로 추적·식별하는 온디바이스 컴퓨터 비전 웹 애플리케이션입니다.

👉 **실시간 웹앱 접속 URL:** [https://kiuza1004.github.io/anti_bug_search/](https://kiuza1004.github.io/anti_bug_search/)  
*(스마트폰 브라우저로 위 주소에 접속하면 별도 설치 없이 바로 실행됩니다)*

---

## 🌟 주요 기능

1. **🪰 비행 모션 탐지 모드 (Flight Motion Radar)**
   - 날아다니는 모기의 빠르고 불규칙한 이동 궤적을 실시간 프레임 차분(Frame Differencing)으로 포착합니다.
   - **스마트 손떨림 필터(Global Motion Rejection):** 사용자가 스마트폰을 들고 움직일 때 발생하는 화면 전체 흔들림은 걸러내고, 2~25px 크기의 미세한 국소 비행체만 정확하게 감지합니다.
   - **비행 궤적 추적선 (Trajectory Trail):** 모기가 어디로 날아갔는지 최근 비행 궤적을 붉은색 잔상선으로 시각화합니다.

2. **🎯 벽면 점 탐지 모드 (Spot Hunter)**
   - 벽지, 천장, 커튼 등에 정지해 있는 모기/벌레를 찾는 모드입니다.
   - **적응형 국소 대비(Adaptive Contrast Spot Detection):** 주변 배경 밝기 대비 어두운 미세 점을 식별하여 타겟팅합니다.
   - **🔬 실시간 4x 디지털 돋보기 (PIP Magnifier):** 감지된 지점을 우측 하단 돋보기 창에 4배 고화질로 확대 렌더링하여, 단순 벽지 먼지/못자국인지 실제 모기 다리와 날개가 있는 벌레인지 육안으로 즉시 판별할 수 있습니다.

3. **🔦 야간 탐색용 조명 (플래시/Torch)**
   - 어두운 침대 밑, 구석, 천장을 비출 수 있는 스마트폰 하드웨어 플래시 토글 기능을 지원합니다.

4. **🔍 원터치 줌 (1x / 2x / 3x)**
   - 높은 천장이나 손이 닿지 않는 거리에 있는 벌레를 확대하여 집중 감지합니다.

5. **🔔 오디오 비프음 및 스마트폰 진동 알림**
   - 벌레가 탐지선에 포착되는 즉시 비프음(Web Audio) 및 햅틱 진동(`navigator.vibrate`)으로 사용자에게 알려줍니다.

6. **📸 증거 스냅샷 캡처**
   - 감지 마커와 날짜가 기록된 고화질 이미지를 원클릭으로 기기에 저장할 수 있습니다.

## 🚀 실행 방법

### 방법 1. 간편 실행 (Windows)
1. 폴더 내의 **`start_server.bat`** 파일을 더블 클릭합니다.
2. 콘솔 창에 표시되는 주소로 접속합니다:
   - **PC 브라우저:** `http://localhost:8000`
   - **핸드폰 브라우저:** 콘솔에 표시된 로컬 IP 주소 (예: `http://192.168.0.x:8000`)

### 방법 2. 파이썬 명령어로 직접 실행
```bash
python server.py
```

## 📱 스마트폰(핸드폰)에서 카메라 권한 설정 안내

최신 모바일 브라우저(크롬, 사파리)는 로컬 Wi-Fi IP 접속 시 카메라 접근 보안 설정이 필요할 수 있습니다:

### 안드로이드 크롬(Chrome)
1. 스마트폰 크롬 주소창에 `chrome://flags` 를 입력합니다.
2. 검색창에 **`unsafely-treat-insecure-origin-as-secure`** 를 검색합니다.
3. 해당 항목을 **Enabled**로 변경하고, 아래 입력란에 PC 서버 주소(예: `http://192.168.0.15:8000`)를 입력합니다.
4. 하단의 **Relaunch(다시 시작)** 버튼을 누르면 스마트폰 카메라가 즉시 동작합니다.

### 아이폰(iOS Safari) 또는 별도 설정 없이 바로 쓰려면
- 본 프로젝트는 순수 정적 웹 기술(HTML/CSS/JS)로 개발되었으므로, **GitHub Pages** 또는 **무료 웹 호스팅(Netlify/Vercel)**에 파일을 업로드(무료)하면 전 세계 어디서든 기본 HTTPS 링크 하나로 스마트폰에서 즉시 카메라를 켜고 사용할 수 있습니다.

## 🔒 비용 및 프라이버시

- **100% 무료 & 비용 0원:** 유료 클라우드 비전 API를 일체 사용하지 않으며, 모든 영상 처리는 사용자의 기기(온디바이스) 내에서 실시간으로 처리됩니다.
- **프라이버시 완벽 보호:** 카메라 영상이 외부 서버나 인터넷으로 절대 전송되지 않습니다.
- **높은 하위 호환성:** 무거운 최신 프레임워크나 외부 패키지 의존성 없이 순수 표준 Web API(Canvas 2D, WebRTC, Web Audio)로 제작되어 구형 스마트폰부터 최신 스마트폰까지 오류 없이 가볍고 부드럽게(60 FPS) 구동됩니다.
